# Effectum / ReIfy product and commercial boundaries

## Public free core

This repository and its publicly committed code are MIT licensed. This includes the runtime, local MCP server, mock/provider hooks, local memory effects and JSON persistence, cancellation and step limits, policy callbacks, diagnostic traces, tests, examples, and documentation.

The core remains free to download and use. MIT permits personal and commercial use, modification, and redistribution subject to its notice requirements. Descriptions such as “local single-user” identify the implementation's supported deployment, not a legal restriction against company use or modification.

Publishing code in a public branch or pull request makes it accessible even before it is merged or published to npm. Previously granted MIT rights are not revoked by moving development, deleting a branch, or changing repository visibility. No promise is made that previously public code can become exclusive again.

## Separate commercial product

Future proprietary applications and service implementations are developed in a separate private repository. Planned paid value includes managed hosting and updates, team workspaces and administration, organization-wide permissions and approval workflows, centralized operational records, managed shared storage, backups and monitoring, enterprise integrations, deployment assistance, and support.

The public core's existing persistence, policy, and tracing code is not claimed as exclusive commercial technology. Company products may build on it while providing additional software and services. Private source is not included in the public npm package or copied into public branches, issues, demos, or workflows.

This is a product boundary, not an amendment to the MIT license. Merely making a repository private does not change the license on MIT material copied into it. Such material retains its original license and notices. New proprietary source is separately identified and subject to commercial terms.

## Pricing principle

The downloadable MIT core is free. Optional commercial products and services will use sustainable paid pricing that covers engineering, maintenance, support, security work, infrastructure, administration, and a margin to fund continued development. We do not promise hosting or other paid offerings “at cost.”

No numeric prices, margins, quotas, unlimited-usage promises, enterprise SLAs, or release dates are established by this document. Plan fees, included allowances, usage charges, and any third-party provider fees must be disclosed before purchase. Proposed paid features are a roadmap, not currently available products.

## Development rule

Use this public repository for core fixes and explicit free-core changes only. Develop new commercial capabilities privately. Do not merge or publish private product code into this repository. Sharing a binary or hosted service does not require publishing its proprietary source, but included third-party license obligations still apply.
